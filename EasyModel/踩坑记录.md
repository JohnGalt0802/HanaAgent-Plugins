# 踩坑记录：stl-viewer-app

## electron 二进制下载（2026-08-10 卡了 3 次）

**现象**：`node node_modules/electron/install.js` 静默"成功"但 dist 里没有 electron.exe，或只有空壳（locales）。
**根因**：npmmirror 镜像偶发返回 0 字节 zip，install.js 不校验完整性；npm install 触发 electron postinstall 重建时，GitHub 直连超时（20.205.243.166:443 ETIMEDOUT），且 rebuild 失败会回滚删掉已装好的 dist。

**解法（手动三步）**：
1. `curl.exe -sSL -o electron.zip "https://npmmirror.com/mirrors/electron/<版本>/electron-v<版本>-win32-x64.zip"`（版本看 node_modules/electron/package.json，zip 应 ~127MB）
2. 校验大小 >100MB，否则删了重下（install.js 不校验，会拿空文件"成功"）
3. `tar.exe -xf electron.zip -C node_modules/electron/dist`（tar 比 Expand-Archive 快）

**预防**：本项目的 npm install 一律加 `--ignore-scripts`（electron 二进制用上面的方式单独维护），避免 postinstall 重建触发 GitHub 超时 + 回滚。

## electron-builder 离线打包（2026-08-10）

**现象**：打包时反复 `connect ETIMEDOUT 20.205.243.166:443`（GitHub IP），
即使设了 `ELECTRON_BUILDER_BINARIES_MIRROR` 也挡不住（有的下载源不走这个变量）。

**要点**：
1. build 配置加 `"electronDist": "node_modules/electron/dist"`，
   打包直接用本地 electron，不下载 130MB zip（关键！）
2. 工具链手动缓存到 `%LOCALAPPDATA%\electron-builder\Cache\`：
   winCodeSign-2.6.0 / nsis-3.0.4.1 / nsis-3.0.4.2 / nsis-resources-3.4.1，
   从 `https://registry.npmmirror.com/-/binary/electron-builder-binaries/` 下 .7z
3. 7z 解压：Windows 自带 tar 不支持 LZMA，需 7zr.exe（单文件版，官网 7-zip.org/a/7zr.exe）
4. nsis-3.0.4.1.7z / 7zip-win-x64.tar.gz / nsis-resources 是 portable 目标必需，网络好时一次下载成功
5. 网络好时直接跑 `npx electron-builder --win portable` 最省事，重试几次即可

## three r185 本地化（2026-08-10）

**坑**：three.module.js 在 r150+ 拆分了 `three.core.js`（核心），
只复制 three.module.js 会导致模块图静默失败（页面无 console 报错、白屏，进程还活着）。
**解法**：`node_modules/three/build/` 整个目录复制到 vendor/，一个文件都不能少。

## 渲染层调试法（正式版也保留）

- main.js 里 `win.webContents.on('console-message')` 把渲染层 console 落盘 console.log
- `--enable-logging` 在 Windows 上抓不到渲染层 console，别依赖它
- app:// 协议 handler 里记录每个请求，404 一目了然（这次就是靠它找到 three.core.js）
- 最终验收标准：窗口标题带模型名（如 `cube.stp — 3D Viewer`），比进程存活可靠

## NSIS 打包失败二连（2026-08-14）

**现象**：
pm run dist 先报 warning treated as error（install function EasyModelFinishCreate not referenced），
关掉后报 ssistedInstaller.nsh on line 48 语法错误。

**根因**：
1. electron-builder 的 NSIS warning 默认当 error（warningsAsErrors 默认 true），installer.nsh 里自定义完成页函数未被引用即失败
2. Page custom 只接受两个函数参数，带标题/按钮文本（"安装完成"/"上一步"/"完成"）是非法语法（NSIS 的 Page custom 没有 MUI 那套标题参数）

**解法**：
1. package.json nsis 配置加 "warningsAsErrors": false
2. Page custom EasyModelFinishCreate EasyModelFinishLeave 去掉三个字符串参数

## 2026-08-17 预览条卡死
- 现象：导入文件夹后 UI 冻结，只剩预览条滚动条活着
- 根因：缩略图创建第二个 WebGL 渲染器 → Chromium GPU 上下文数有限 → 主渲染器上下文被挤掉 → canvas 停止重绘
- 修复：缩略图改用主渲染器临时 setSize(160,120) 渲染 + toDataURL 捕获 + 恢复尺寸；resize 事件加 isThumbRendering 守卫防 setSize 循环
- 关键：preserveDrawingBuffer: true 必须在创建渲染器时设置（运行时改不了）
- 注意：2D canvas 投影方案也验证过可用（完全不碰 WebGL），作为备选
